# ChugimCenter-Client – אתר "אורות"

לקוח React לאתר רישום לחוגי בנות. הלקוח מתחבר לשרת [ChugimCenter](https://github.com/cz0534154011/ChugimCenter) (ASP.NET Core Web API) ומציג את כל האפשרויות שלו לכל תפקיד.

## טכנולוגיות

- React 19, ‏Vite, ‏React Router ו-Axios.
- עיצוב: CSS שנכתב בעצמנו (`src/styles/global.css`), בעברית מימין לשמאל, עם תצוגה מותאמת לטלפון.
- בלי ספריות עיצוב ובלי ספריית אייקונים – האייקונים והלוגו הם SVG בקוד.

## הרצה מקומית

דרישות: Node.js 20.19 ומעלה, והשרת ChugimCenter רץ (פרופיל https, ‏`https://localhost:7200`).

```
npm install
npm run dev
```

האתר נפתח ב-`http://localhost:5173`. זו הכתובת שמוגדרת ב-CORS של השרת.

כתובת השרת נקבעת במשתנה `VITE_API_URL`. אם הוא לא מוגדר, נעשה שימוש ב-`https://localhost:7200`. לשינוי בפיתוח: מעתיקים את `.env.example` לקובץ `.env.development`. בהעלאה לענן מגדירים אותו בהגדרות האתר.

## מה יש באתר

| תפקיד | מסכים |
|---|---|
| כולם | עמוד בית, כל החוגים (סינון, מיון ועמודים מול השרת), דף קבוצה, התחברות, הרשמה |
| משתתפת | רישום לחוג (כולל הצגת 409 וכפתור "נסי שוב"), החוגים שלי (פעילים ומבוטלים), ביטול רישום, הפרטים שלי |
| מדריכה | הקבוצות שלי עם תפוסה, רשימת תלמידות (עם הדפסה) |
| מנהלת | סקירה, ניהול קבוצות (יצירה, עריכה עם חישוב אוטומטי של היום ותאריך הסיום, השבתה, מחיקה), רישומים ותשלומים, תחומים, משתמשות ויצירת מדריכה |

## איך הלקוח מדבר עם השרת

- ה-token נשמר אחרי ההתחברות ב-sessionStorage, ונשלח בכל בקשה בכותרת `Authorization` (`src/api/client.js`). כל לשונית מחוברת בנפרד.
- הדגמת 409: בשתי לשוניות מתחברים כאסתר וכלאה, פותחים בשתיהן את קבוצה 3 (נשאר בה מקום אחד) ולוחצים "הרשמה לחוג" – הראשונה נרשמת, והשנייה מקבלת הודעה ברורה וכפתור "נסי שוב".
- כל שגיאה מהשרת (‏ErrorResponse) מוצגת באותה דרך: הודעה כללית, או שגיאה ליד השדה המתאים ב-400.
- ‏401 בבקשה מחוברת (ה-token פג) – התנתקות ומעבר להתחברות.
- ‏409 ברישום לחוג – הודעה ברורה ("המקום נתפס על ידי משתמשת אחרת" או "אין מקומות פנויים") וכפתור "נסי שוב", שמרענן קודם את מספר המקומות מהשרת.
- התפריט והכתובות המוגנות תלויים בתפקיד, אבל כל הרשאה נבדקת גם בשרת.

## נגישות

ניווט מלא במקלדת וקישור "דילוג לתוכן", תווית לכל שדה, שגיאות שמוקראות לקורא מסך, חלונות אישור שמחזיקים את המיקוד, כותרת לכל דף, ניגודיות צבעים תקנית, וכיבוד ההגדרה "הפחתת תנועה".

## מבנה התיקיות

```
src/
  api/         הפנייה לשרת (Axios) וכל ה-endpoints
  auth/        מצב ההתחברות והגנה על כתובות
  components/  רכיבים משותפים: כותרת, כרטיס חוג, שדות, חלונות, עמודים
  hooks/       טעינת נתונים, טפסים וכותרת דף
  pages/       המסכים, לפי תפקיד (member, instructor, admin)
  styles/      העיצוב
  utils/       תאריכים, שעות ובדיקות קלט
```
